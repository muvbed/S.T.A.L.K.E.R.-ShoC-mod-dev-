# S.T.A.L.K.E.R. ShoC mod (dev)

- многочисленные исправления ошибок во всех аспектах оригинальной игры
- расширение игрового мира: периодические Выбросы, респаун артефактов, динамические аномалии
- улучшение поведения NPC: дополнение схем озвучки, улучшенное поведение в бою и вне боя, динамическая торговля
- новые возможности для игрока: сброс рюкзака, переработанный инвентарь, разведение костров, создание тайников
- Оффлайн - A-Life и Система динамических новостей из мода АМК
- обновлённый пользовательский интерфейс (отдельная благодарность Mejisai)
  ...и многое другое.
